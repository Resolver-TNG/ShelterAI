## 撮影方式の定義

| 方式 | 略称 | 説明 |
|---|---|---|
| 画面収録 | 📱REC | iPhone画面収録（Settings > Control Center > Screen Recording） |
| 外撮り | 📷EXT | iPadまたは別カメラでiPhoneを物理的に撮影 |
| 静止画 | 🖼️IMG | Keynote/アセット画像をResolveで挿入 |

**基本方針:**
- UIの詳細を見せたい → 📱REC（解像度が圧倒的に高い）
- 「実際のiPhoneで動いてる」感を出す → 📷EXT
- タイトル/エンド → 🖼️IMG

## 撮影手順（マスター向けチェックリスト）

### 事前準備
- [ ] iPhoneに開発者モードON → Xcodeビルド → アプリ動作確認
- [ ] サンプルデータが正常投入できるか確認
- [ ] カメラ自動シャッターが免許証で発火するか確認
- [ ] Gemma 4モデルが正常ロードされるか確認（初回数秒かかる）
- [ ] 通知OFF（おやすみモード + 画面収録中の通知非表示）
- [ ] バッテリー80%以上
- [ ] 画面の明るさ最大（撮影用）

### 画面収録の設定
- Settings > Control Center > Screen Recording 有効化
- マイクOFF（ナレーションは後から合成）
- **赤ステータスバー対策:** Resolveで上部をクロップ or iPhone 16系はDynamic Island内に収まる

### 外撮りの設定
- 撮影デバイス: iPad or 三脚固定の別カメラ
- 明るい場所（自然光ベスト）
- 背景: シンプル（白テーブル or デスク）
- **手ブレ対策:** 可能なら三脚/スタンド使用

### 撮影順序（効率重視）
1. **📱REC一括撮影**（30分）
   - 機内モードON
   - アプリ起動 → サンプルデータ → カメラ → 検索 → AI → CSV
   - 失敗してもやり直しが楽（録画止めて再開するだけ）
2. **📷EXT撮影**（15分）
   - Scene 2-A: 手にiPhone、コントロールセンター引き下ろし
   - Scene 5-B: 免許証をかざすショット
3. **素材整理** → Resolveに放り込んで編集

### DaVinci Resolve 編集ノート
- **解像度:** 1080p（YouTube + Kaggle再生に十分）
- **フレームレート:** 30fps（画面収録のデフォルトと合わせる）
- **モザイク:** 免許証の顔写真・番号 → Fusion > Planar Tracker + Rectangle Mask
- **テロップ:** Text+ノード、白文字+半透明黒背景帯（下部1/5）
- **速度変更:** AIストリーミング部分は1.5-2x（Speed Change）
- **BGM:** -18dB〜-24dB（テロップ読みの邪魔にならない程度）
- **書き出し:** H.264, 1080p, 8Mbps → YouTube Upload

## ナレーション

**方式:** テロップのみ（英語）。音声ナレーションなし。

**理由:**
- Kaggle審査は国際 → 英語テロップで十分伝わる
- 日本語ナレーションは非日本語話者に届かない
- テロップのみの方が撮影〜完成が速い（TTS調整のコストゼロ）
- BGMだけの方がプロっぽく見える

**代替案（時間に余裕があれば）:**
- 英語ナレーション追加（ElevenLabs or Irodori-TTS）
- ただし提出〆切を考えると今回はテロップのみ推奨

## 外撮り撮影ガイド（X-H2 4K）

### 共通設定

| 項目 | 設定 |
|---|---|
| カメラ | Fujifilm X-H2 |
| 解像度 | 4K (3840×2160) 30fps → 最終1080pダウンスケール（シャープネス向上） |
| カラープロファイル | Eterna or Pro Neg.Std（落ち着いたテック系トーン） |
| WB | 自然光: Auto / 蛍光灯: 5000K前後 |
| F値 | f/4〜5.6（手元全体にピント、ボケすぎない） |
| 三脚 | 必須（両ショットとも） |
| 録音 | 不要（マイクOFF推奨、BGMのみ） |
| 背景 | シンプルなデスク（白 or 木目）。生活感あるものは外す |
| 照明 | 自然光 or デスクライト斜め45°（画面反射を避ける） |

### 配置図（上から見た図）

```
        [照明]
         ↓ 斜め45°
  
  [X-H2 三脚] ──→ [デスク上: iPhoneスタンド + 操作する手]
   距離: 50-70cm
   高さ: デスク面+20cm（やや俯瞰）
```

### Scene 2-A: iPhone手持ち → コントロールセンター（3秒）

**目的:** 「物理的なiPhoneで動いてる」を一瞬で伝える

| 項目 | 設定 |
|---|---|
| 画角 | 上半身〜手元（50-80mm相当） |
| アングル | やや俯瞰（15-20°上から） |
| フォーカス | iPhone画面付近にAF |

```
┌─────────────────────┐
│                     │
│    ┌───────┐        │
│    │iPhone │  ← 画面が読める程度に寄る
│    │  📱   │
│    └───┬───┘        │
│        │手          │
│   ─────┴─────       │
│     テーブル         │
└─────────────────────┘
```

- **構図:** iPhone画面が画面中央やや上、手と腕が自然に入る
- **ポイント:** iPhone画面が**読める必要はない**（UIの詳細は画面収録で見せる）。「手にデバイスがある」認識だけで十分
- **照明注意:** 画面の反射を避ける → 光源を正面に置かない

### Scene 5-B: 免許証をかざす（5秒）

**目的:** 「物理カードを物理デバイスにかざしてる」リアリティ

| 項目 | 設定 |
|---|---|
| 画角 | 手元クローズアップ（80-120mm相当） |
| アングル | 真横〜やや斜め上（カードとiPhone両方映す） |
| フォーカス | 免許証→iPhone画面にAF追従 |

```
┌─────────────────────┐
│                     │
│  ┌─────┐  ┌───┐    │
│  │免許証│→ │📱 │    │  ← カードをかざす動き
│  │     │  │   │    │
│  └─────┘  └───┘    │
│     左手    右手/    │
│           スタンド   │
└─────────────────────┘
```

- **構図:** 左手に免許証、右側にiPhone（スタンドに立てると手ブレ回避）
- **動き:** 免許証をゆっくりカメラの前に持っていく（急ぐと伝わらない）
- **フォーカス送り:** X-H2のAFで免許証表面→iPhone画面に自然追従
- **ポイント:** 免許証の文字が一瞬読めるくらい寄ると「本物感」。モザイクはResolveで後処理
- **iPhoneの固定:** スマホスタンド推奨。片手免許証+片手iPhone持ちだと手がプルプルする
